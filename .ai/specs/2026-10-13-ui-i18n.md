# UI internationalization

Approved scope: default Simplified Chinese UI; English remains selectable in
global Settings → Appearance. Save the language in workspace UI state, with a
browser mirror for first paint. Change language without reloading or discarding
in-progress forms. Translate UI-owned copy and accessible labels throughout the
cockpit; preserve user input, source code, commands, model output and third-party
content. Use source English as catalog keys and numbered placeholders for dynamic
values. Dates and numbers follow the selected language.

Implementation and verification:

1. Add locale contract, catalog, reactive subscription and preference controller.
   Verify Chinese defaults, invalid preferences, interpolation, switching,
   persistence, server reconciliation and failed saves.
2. Extract and translate UI messages using a syntax-aware migration; keep machine
   values unchanged. Review shared navigation and task/workflow/settings terms.
3. Add the Settings control and first-paint language. Verify a Chinese installation
   and live English/Chinese switching, then run type checks, unit tests and build.
