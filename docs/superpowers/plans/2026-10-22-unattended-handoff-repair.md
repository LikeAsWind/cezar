# Unattended 交接修复实施计划

> 使用 executing-plans 按任务执行。保留官方 skill 原文，宿主只负责路径、状态与证据交接。

**目标：** 修复审计中的九项交接缺陷，使所有执行分支、裁决、返修和发布恢复使用同一任务的当前证据。

**设计：** 官方 plan workspace 和 progress.md 是执行事实来源；宿主保存引用及分支状态，不复制官方账本。节点成功必须满足其交接契约。验证失败也提供当前诊断与差异，冻结的检查不得被静默替换。发布与通知的恢复只重试失败操作。

**规格：** docs/superpowers/audits/2026-10-22-unattended-artifact-handoff-audit.md

## 实施清单

- [x] Task 1：官方 workspace、账本、返修报告与当前问题按需传递；核对 plan-path 身份，保留现有报告。
- [x] Task 2：验证失败生成当前诊断、差异，失效旧凭据；扩展范围必须覆盖冻结验证范围。
- [x] Task 3：路由档位与执行完成、审查、交付门槛校验；native 和 SDD 按各自官方完成契约执行。
- [x] Task 4：持久传递用户补充、恢复正确发布步骤，保留审核人和通知失败原因。
- [x] Task 5：更新节点中文输入说明，运行回归、类型检查及分支交接测试，审查最终差异。

## 验证要求

先增加能复现审计缺陷的失败测试，再修改生产代码。覆盖首次验证失败、过期凭据、错误降档、未完成账本、首次审查与限定复查、裁决往返、范围扩大、发布失败后恢复以及跨节点用户补充。不得调用真实通知或发布。不得把历史任务数据改成通过。
