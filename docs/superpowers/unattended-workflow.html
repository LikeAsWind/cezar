标准：同一上下文逐任务实现

superpowers:executing-plans
  1. 实现者在同一会话读取计划与任务简报。
  2. 每项任务执行 TDD、验证、自检并更新账本。
  3. 完成所有任务后，交给宿主验证与独立全分支审查。

不为每项任务另开实现者和审查者。

复杂：具备条件才使用逐任务独立上下文

superpowers:subagent-driven-development
  1. 协调者为每项任务准备简报，派发独立实现者。
  2. 实现者实现、测试、自检；独立任务审查者核对规格与质量。
  3. 有发现则按原始 v7 规则修复并限定复查，再记录任务完成。
  4. 重复下一任务；全部完成后仍要宿主验证与独立全分支审查。

仅在任务独立且已观察到派发能力时走 SDD；紧耦合、无能力或能力未知则走 execute-deep-native，保留 deep 风险约束与独立全分支审查。上面的 SDD 子流程发生在技能内部。

共享裁决者：有问题才调用，回答后返回原节点

brainstorming 负责提问与设计；adjudicator 读取需求、地图和证据回答。计划、实现、返修也可以复用。同一任务全程共用最多 8 轮；缺失产品授权时阻塞。
